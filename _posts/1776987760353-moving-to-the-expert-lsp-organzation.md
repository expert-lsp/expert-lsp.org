Short update: we have decided to move the project to the [expert-lsp](https://github.com/expert-lsp) organization on GitHub.

While `expert` is still the official language server implementation for Elixir, we needed more flexibility with how we manage access to the projects that just weren't possible with the `elixir-lang` organization.

PS: [v0.1.1](https://github.com/expert-lsp/expert/releases/tag/v0.1.1) is now out. 🎉
